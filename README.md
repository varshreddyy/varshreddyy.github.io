## How it's built

One static HTML file with inline CSS. There's no framework or build step, and no JavaScript. It supports light and dark mode (following the system setting) and works at phone width.

```
index.html    The whole site
resume.pdf    Resume linked from the site
```

## Updating

Edit `index.html` or replace `resume.pdf`, then commit to `main`. GitHub Pages republishes within a minute or two. To preview locally, open `index.html` in a browser.
