LawGPT: Legal AI Assistant

Code

A RAG research assistant for Indian law, with outcome prediction.

  • 10,200 labelled judgments
  • 3 outcome classes
  • Local LLM, no data leaves the machine
  • Retrieves relevant Supreme Court and High Court judgments with Legal-BERT embeddings in ChromaDB, one result per case.
  • A local LLM (phi3 via Ollama) answers using only the retrieved text, in a fixed structure: principle, reasoning, sections, answer.
  • A Logistic Regression classifier predicts Allowed / Dismissed / Partly Allowed with a confidence score and shows similar past cases.

Blood Group Classification from Fingerprints

Code

A hybrid CNN + graph neural network image classifier.

  • 79.3% test accuracy
  • 8 classes
  • 1,600 held-out images
  • EfficientNet-B3 feature maps become a 49-node k-NN graph, classified by a Graph Attention Network.
  • Averages predictions over 7 augmented views of each image at test time.
  • Flask app for predictions from uploaded images or a webcam.
PyTorchPyTorch GeometricEfficientNetGATFlask

Research and learning project. There's no established biological link between fingerprints and blood groups, so this isn't for medical use.

Seq2Seq Chatbot from Scratch

Code

An encoder-decoder chatbot with attention, built and trained in PyTorch.

  • 84K dialogue pairs
  • 21.6K-word vocabulary
  • 50K training iterations
  • GRU encoder and a decoder with Luong dot-product attention, trained on the Cornell Movie-Dialogs corpus.
  • Teacher forcing, gradient clipping and checkpointing in a hand-written training loop.
  • Served through a FastAPI endpoint with a React chat interface.
